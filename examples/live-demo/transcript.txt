Read-only replay of actual CLI diagnosis output from genuine manually approved runs.
No target command, approval, image pull or Docker call is made by this generator.
Entry point shown as reprodoctor; captured via python -I -m reprodoctor.
Project paths are normalized. Replay timing is paced, not a screen recording.
Frozen corpus: 7 executions, 5 abstentions. Tiny public sample; no general accuracy claim.
