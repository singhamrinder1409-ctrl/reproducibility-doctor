# Changelog

## 0.1.0.dev0 — experimental preview (2026-10-27)

- Commit-pinned local/public GitHub intake and bounded immutable snapshots.
- Ordered README extraction, static checks and evidence-backed JSON/Markdown reports.
- Digest-bound plans, interactive approval, dry-run and resumable fixture approvals.
- Offline disposable Docker execution, bounded capture and exact-journal recovery.
- Reference state/failure, network, resource, log, 120/600-second deadline, interruption, recovery, path and offline-wheel acceptance on Docker Desktop Linux ARM64.
- Frozen public 12-fixture evaluation: seven executions, five explicit abstentions, seven confirmed removals; small-sample and unknown-cause limits retained.
- Genuine sample reports, static walkthrough and read-only evidence replay.
- MIT license, contributor/security/dependency docs and Linux/macOS CI on Python 3.12–3.14.

This remains experimental. Containers do not make arbitrary code completely safe. Other execution platforms, broader package workflows and real-world setup accuracy are unverified. No stable release or PyPI publication is claimed.
